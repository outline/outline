# Staff

The Staff module manages your team. Control who has access and what they can do.

## User Roles

Petso has two main roles:

| Role | Access Level | Description |
|------|--------------|-------------|
| **Admin** | Full | All features, settings, and management |
| **Staff** | Limited | Daily operations: POS, boardings, inventory |

### Admin Capabilities
- Manage all branches
- Invite and manage staff
- Access financial reports
- Configure settings
- Manage loyalty programs

### Staff Capabilities
- Process POS transactions
- Manage boardings
- View and update inventory
- Limited branch access (as assigned)

## Inviting Staff

### Step 1: Open Staff Management
1. Go to **Settings** → **Staff**
2. Or click **Invite** from any staff-related page

### Step 2: Enter Details
Fill in the invite form:
- **Email** — Must be a valid email address
- **Role** — Admin or Staff
- **Branch** — Which branch they'll work at

### Step 3: Send Invite
Click **Send Invite**.

The invited person will receive an email to:
1. Create their account
2. Set their password
3. Access the system

### Pending Invites
Invites show in the staff list with "Pending" status until accepted.

## Managing Staff

### View Staff List
See all team members with:
- Full name
- Email
- Role
- Assigned branches
- Status (Active/Pending)

### Edit Staff
1. Find the staff member
2. Click **Edit**
3. Update their details
4. Save

### Change Role
Admins can change staff roles:
1. Edit the staff member
2. Select new role
3. Save

### Remove Staff
1. Find the staff member
2. Click **Remove**
3. Confirm removal

> **Note:** Removed staff lose access immediately. Their historical records are preserved.

## Branch Assignments

Staff can be assigned to:

### Single Branch
One specific location. Staff can only operate within that branch.

### Multiple Branches
Two or more locations. Staff can switch between assigned branches.

### All Branches
Typically for admins only. Full access to all locations.

### Assignment Best Practices
- Assign staff to their primary work location
- For multi-location workers, assign all relevant branches
- Review assignments quarterly

## Session and Security

### Active Sessions
Staff sessions are tracked:
- Last login time
- Active status
- Browser/device info

### Security Measures
- Password requirements enforced
- Session timeout after inactivity
- Admin can force logout if needed

## Onboarding Checklist

When onboarding new staff, use the checklist:

- [ ] Send invite email
- [ ] Explain their role and permissions
- [ ] Assign to correct branch
- [ ] Train on relevant features (POS, Boarding, etc.)
- [ ] Set up initial password
- [ ] First login verification

## Best Practices

### Access Control
- Follow least-privilege principle
- Give staff only the access they need
- Review access regularly

### Password Security
- Require strong passwords
- Change passwords periodically
- Never share credentials

### Role Management
- Minimum number of admins
- Assign "Manager" role for senior staff
- Document role assignments
