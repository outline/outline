# Accounting

The Accounting module gives you financial visibility. Track revenue, expenses, and manage petty cash across your business.

## Financial Overview

### Dashboard Metrics

| Metric | Description |
|--------|-------------|
| **Monthly Revenue** | Total sales income this month |
| **Monthly Expenses** | Total spending this month |
| **Monthly Profit** | Revenue minus expenses |
| **Petty Cash Balance** | Cash on hand |

### Revenue Trend

The revenue trend chart shows:
- Monthly revenue totals
- Growth or decline over time
- Comparison to previous periods

Use this to identify:
- Peak sales months
- Slow seasons
- Growth trends

## Expense Tracking

### Recording Expenses

1. Go to **Accounting** → **Expenses**
2. Click **Add Expense**
3. Fill in the details:
   - Category (required)
   - Description
   - Amount (required)
   - Date
   - Payment method
   - Branch
   - Notes

### Expense Categories

| Category | Examples |
|----------|----------|
| **Supplies** | Pet food, cleaning materials, office supplies |
| **Utilities** | Electricity, water, internet |
| **Maintenance** | Repairs, equipment service |
| **Marketing** | Ads, promotions, printing |
| **Salaries** | Staff wages (if applicable) |
| **Other** | Miscellaneous expenses |

### Expense Reports

View expenses by:
- Date range
- Category
- Branch
- Amount range

## Petty Cash Management

### What is Petty Cash?

Petty cash is the cash kept on hand for small purchases and reimbursements.

### Petty Cash Operations

#### Record Disbursement
1. Go to **Accounting** → **Petty Cash**
2. Click **Record Disbursement**
3. Enter:
   - Amount
   - Description
   - Date
   - Received by
4. Save

#### Track Balance
The system maintains petty cash balance:
- Opening balance
- Disbursements
- Current balance

#### Per-Branch Petty Cash
Each branch can have its own petty cash:
- Branch A petty cash
- Branch B petty cash
- Branch C petty cash

## Account Types

Petso uses standard accounting categories:

| Type | Description | Examples |
|------|-------------|----------|
| **Asset** | What you own | Cash, inventory, equipment |
| **Liability** | What you owe | Accounts payable, loans |
| **Equity** | Owner's stake | Capital, retained earnings |
| **Revenue** | Income earned | Sales, service fees |
| **Expense** | Money spent | Supplies, utilities, wages |

## Best Practices

### Daily
- Record all expenses immediately
- Reconcile petty cash at end of day

### Weekly
- Review revenue trends
- Check for unusual expenses
- Update petty cash balance

### Monthly
- Generate financial reports
- Analyze profit margins
- Plan for upcoming expenses

### Record Keeping
- Attach receipts to expenses
- Note unusual transactions
- Keep records organized by date

## Common Scenarios

### Petty Cash Run Out
1. Replenish from main cash
2. Record the transfer
3. Continue operations

### Unusual Expense
1. Verify with receipt
2. Categorize correctly
3. Note in description
4. Review for patterns

### Revenue Dip
1. Check data entry errors
2. Compare to previous periods
3. Investigate cause
4. Adjust operations if needed
