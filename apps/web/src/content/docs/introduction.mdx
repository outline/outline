# Introduction

Welcome to **Petso** — the all-in-one platform designed for pet care businesses, cat daycares, and multi-branch petshops. This documentation will guide you through every feature and capability.

## What is Petso?

Petso brings together boarding management, point-of-sale, inventory tracking, customer loyalty, and financial reporting into a single, unified platform. Whether you run one location or fifty, Petso scales with your business.

> **Good to know:** Petso is built with a multi-tenant architecture. Each business (tenant) has isolated data, staff accounts, and branch configurations.

## Core Capabilities

Petso consists of ten integrated modules:

| Module | What it does |
|--------|--------------|
| **Dashboard** | Real-time business metrics at a glance |
| **POS** | Fast checkout with Cash, Transfer, and QRIS |
| **Products** | Catalog management with stock tracking |
| **Boarding** | Pet check-in/out with status workflow |
| **Branches** | Multi-location support with isolated data |
| **Staff** | Team invites and role-based permissions |
| **Loyalty** | Points-based rewards with tier system |
| **Accounting** | Financial summaries and expense tracking |
| **WhatsApp** | Automated customer notifications |
| **Auth** | Secure login with session management |
